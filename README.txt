RIDA DZAKIYYAH — GLASSMORPHISM PORTFOLIO

Isi folder:
- index.html   : struktur website
- style.css    : seluruh styling dan responsive layout
- script.js    : navigasi mobile, active menu, dan tahun footer
- assets/      : aset visual

Cara menjalankan:
1. Extract ZIP.
2. Buka folder di VS Code.
3. Jalankan index.html menggunakan Live Server (disarankan), atau buka langsung di browser.

Mengganti foto profil:
- Siapkan foto portrait PNG/JPG.
- Simpan ke folder assets dengan nama profile.png.
- Di index.html, ubah src="assets/profile-placeholder.svg" menjadi src="assets/profile.png".

Yang perlu kamu personalisasi sebelum dipublikasikan:
- Ganti email hello@rdzvisualab.com dengan email aktif.
- Ganti link LinkedIn dengan profil LinkedIn milikmu.
- Tambahkan link detail project pada masing-masing kartu.
- Ganti deskripsi atau achievement bila ada informasi terbaru.

Catatan:
Project cover saat ini dibuat menggunakan CSS agar website tetap tampil tanpa gambar eksternal.
Website menggunakan Google Fonts; jika offline, font akan fallback ke sans-serif.
